# SkillCraft Technology Internship - Task 2

## Project Title
Data Cleaning and Preprocessing using Pandas

## Objective
The objective of this project is to clean and preprocess the Global Superstore dataset using Python and the Pandas library.

## Tasks Performed
- Loaded the dataset using Pandas
- Explored the dataset using `head()` and `info()`
- Identified missing values
- Removed the `Postal Code` column due to excessive missing values
- Checked and removed duplicate records
- Converted `Order Date` and `Ship Date` to datetime format
- Exported the cleaned dataset to a new CSV file

## Tools Used
- Python
- Pandas
- Google Colab

## Output
- Cleaned Global Superstore Dataset (`Global_Superstore_Cleaned.csv`)
